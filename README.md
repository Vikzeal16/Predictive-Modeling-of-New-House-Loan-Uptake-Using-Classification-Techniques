# New Home Loan Uptake Prediction

This project explores how classification techniques can be used to predict whether a customer will take up a new home loan. The analysis is provided in a Jupyter notebook.

## Project file

- `Predictive Modeling of New House Loan Uptake Using Classification Techniques.ipynb` — notebook containing the project workflow.

## Getting started

Open the notebook in GitHub to preview it, or run it locally with Jupyter Notebook or JupyterLab. Install the Python libraries imported in the notebook before running the cells.

## Scope

This repository presents a learning project. Consult the notebook for the dataset, preprocessing choices, model details, and evaluation results.
